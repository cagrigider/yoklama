## 1. Test Plan Identifier

`TESTPLAN-yoklama-setup`

## 2. Introduction

Other AI Champions must clone Yoklama, configure their own group, and tick meetings without login, without a hosted server, and without Grup 8 PII. This plan is the **integration** layer for that capability.

The BA Gherkin set (`docs/analysis/yoklama-setup/test/testcases-yoklama-setup.en.md`, `@TC-BE-001`…`016` / `@TC-FE-001`…`014`) is the **acceptance** layer. Cases below reference those ids and trace plan criteria as `TASK-KEY#ACn`. They do not re-derive Gherkin as the only content. Extra design effort: isolated temp DB, ADR-0001 upgrade insert, ADR-0003 monthly ordinal, two-transaction import, people 409, live-tick non-regression, HTTP error-code matrix.

Architect ADRs in force: ADR-0001 (SQLite singleton + upgrade insert), ADR-0002 (stdlib import, JSON body), ADR-0003 (fill-gaps weekday / monthly ordinal).

**Not BLOCKED:** every task AC is testable as written.

## 3. Test Items

- TASK-1.1.1 — meeting series fill-gaps
- TASK-1.1.2 — GroupProfile gate and first-run wizard
- TASK-1.2.1 — Settings, header, live-tick preserve
- TASK-1.2.2 — roster import and README field contract
- TASK-1.2.3 — people add, edit, delete
- Runtime: local Python app `python3 app.py` on `http://127.0.0.1:8765`, always from an isolated temp tree

## 4. Features to be Tested

- Empty-clone wizard vs configured meeting list (ADR-0001)
- Operator-upgrade default profile insert (no series, no wizard)
- `seed/people.json` does not skip the wizard
- Don’t-repeat / weekly / biweekly / monthly fill-gaps, including fifth-weekday skip
- `end_date < first_date` rejected with no writes
- Shortening end date never deletes; no `UNIQUE(date)`
- Generated `kind=series`; extras stay `extra`
- Profile+series commit independent of a later rejected import
- Settings reuses fill-gaps; header shows group name
- Live tick, tags, notes, copyable summaries, extra meeting CUD
- NFR-001 one-mark smoke (non-gating)
- CSV / `people.json` / simple xlsx upsert; absentees not deleted
- All-or-nothing validation; exotic xlsx fail-closed; numeric sicil; UTF-8 BOM
- JSON body import; stdlib only; no `requirements.txt`
- People CRUD; 409 duplicate; immutable sicil; confirm cascade
- Turkish wizard, Settings, people forms; empty roster valid
- Position/center on people row, report, and live roster
- Bind `127.0.0.1` not `0.0.0.0`; no password; git omits `data/*.db` and real `seed/people.json`

## 5. Features Not to be Tested

- Hosted multi-user product, login, Teams auto-attendance, guests, managers as users (FRD out of scope)
- Operator Grup 8 production PII (synthetic fixtures only)
- OpenAPI / ba-services (none; extend existing JSON `Handler`)
- NFR-001 as an automated 1s CI gate (architect F-5) — TC-22 is smoke
- BA Gherkin as a separately executed suite — see `excluded_coverage` in the JSON
- `openpyxl` / multipart upload (ADR-0002 forbids)
- Adding `UNIQUE(date)` (must remain absent)

## 6. Approach

### 6.1 Isolated runtime (mandatory)

Never open the operator Grup 8 `data/attendance.db`.

```bash
BASE=/Users/cagri.gider/Documents/AI_Champions/attendance
TEST_ROOT=$(mktemp -d /tmp/yoklama-setup-XXXX)
rsync -a --exclude 'data/*.db' --exclude 'data/*.db-journal' \
  --exclude 'seed/people.json' --exclude '.git' "$BASE/" "$TEST_ROOT/"
mkdir -p "$TEST_ROOT/data"
# If 8765 is busy, stop that Yoklama process for the run — do not point at BASE/data.
cd "$TEST_ROOT"
python3 app.py
# BASE_URL=http://127.0.0.1:8765
```

If the deliverable documents `YOKLAMA_DATA_DIR` / `YOKLAMA_DB`, set it to a temp path instead of copying the tree — still never the operator DB.

Teardown: SIGINT the server; `rm -rf "$TEST_ROOT"`; do not copy the test DB onto `BASE/data`.

### 6.2 Techniques

| Surface | `technique` |
|---------|-------------|
| Profile, series, import, people, meta, meetings, attendance | `curl` |
| Wizard, Settings, people UI, header, live tick | `playwright-cli` |
| README + `git ls-files` | `integration` |

Playwright: Chromium against `BASE_URL`. Expected hashes: `#/` meeting list, `#/settings` Settings, `#/people` people, `#/meeting/:id` live roster. Wizard is the first view when `configured=false` (overlay or `#/setup`). Product copy is Turkish, not `screens.md` English.

### 6.3 Harness contract (substitute documented names)

If README or code comments name different paths, substitute and record it. Defaults:

| Action | Method | Path | Body |
|--------|--------|------|------|
| Meta | GET | `/api/meta` | Response includes `configured` (bool), `groupName` (string); may include `firstDate`, `endDate`, `repeatRule` |
| Save profile + series (wizard and Settings) | PUT | `/api/profile` | `{ "name", "firstDate", "endDate" \| null, "repeatRule": "none"\|"weekly"\|"biweekly"\|"monthly" }` |
| Import | POST | `/api/people/import` | JSON `{ "filename", "text" }` or `{ "filename", "contentBase64" }` — **not** multipart |
| Add person | POST | `/api/people` | `{ "id", "name", "position"?, "center"?, "email"? }` |
| Edit person | PUT | `/api/people/{id}` | `{ "name", "position", "center", "email"? }` — id in path only |
| Delete person | DELETE | `/api/people/{id}` | — |
| Existing | GET/POST/PUT/DELETE | `/api/people`, `/api/meetings`, `/api/meetings/{id}/attendance/{personId}`, `/api/meetings/{id}/roster` | As shipped |

Validation may be HTTP 400 or 422 unless an AC requires **409** (duplicate add).

### 6.4 Synthetic data

RFC 2606 `@example.com`, fictional names (`Jane Doe`, `Ada Lovelace`, `John Q. Public`, `Test User NN`), sicil `10001+`. Never a real corporate domain or Grup 8 roster.

### 6.5 Minimal xlsx (stdlib, no openpyxl)

QA builds a first-sheet workbook with `zipfile` + XML (shared strings or inline strings). Macro-ish fixture: same zip plus `xl/vbaProject.bin`. Encrypted stub: zip with `EncryptedPackage` + `EncryptionInfo`.

## 7. Item Pass/Fail Criteria

A case passes when every step assertion holds. Profile/series rejects must leave `group_profile` and meetings unchanged. Import rejects must leave people unchanged. Delete-cancel must leave person and attendance. Bind case fails if the process listens on `0.0.0.0` or requires a password.

**TC-22 (NFR-001):** PASS if the mark persists and the row updates. Elapsed ≤1s: clean smoke. 1s–5s: PASS with WARNING. Hang >5s: FAIL. Do not use 1s as a flaky CI gate.

A task item passes when every case tracing that task’s ACs passes.

## 8. Suspension / Resumption Criteria

Suspend if `python3 app.py` cannot bind `127.0.0.1:8765`, if tests would use the operator `data/attendance.db`, if profile-save or people-write routes are missing (precondition-blocked, kind: env), or if any case writes into `BASE/data`.

Resume when an isolated temp tree runs and harness routes respond. Re-run **TC-1, TC-9, TC-11, TC-17** as the foundation gate.
